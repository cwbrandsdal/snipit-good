snippit-good settings

Capture shortcut

Works anywhere — press it to start a new snip.

Recording shortcut

Starts a screen recording right away — press it again to stop. You can also press Tab in the snip overlay to switch between snip and record.

Copy on capture

Put every new snip straight on the clipboard. Recordings copy as a file you can paste into chats and folders.

Adjust before recording

After you drag out an area, resize or move it and press Record when you're ready. Turn off to start recording the instant you release the mouse.

Record system audio

Include the sound you hear in screen recordings.

Updates

You're on v…. New versions install from GitHub releases.

Recent snips

The bar keeps your last 3 captures — snips and recordings alike — and fades away after ~10 seconds; use its pin button to keep it open. Older captures are removed automatically; save anything you want to keep.
